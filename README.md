# 関数グラフ マスター道場 | 直線・放物線・双曲線

関数のグラフと式の対応を直感的に学べるウェブサイトです。
直線・放物線・双曲線を題材に、「グラフ→式」「式→グラフ」の双方向で反復練習ができます。

🌐 **ウェブサイトURL**
https://logigritlab.github.io/graph-function-drill_JP

## ✨ 主な機能

* **選べる3つの学習モード**
  * **✎ 自由練習モード**: 自分のペースでじっくり問題に取り組むモードです。
  * **⏱ 10問タイムアタック**: スピードと正確さを競い、クリアタイムと正解数に応じてS〜Cランクで評価されます。
  * **🔬 グラフ実験室**: スライダーで係数（$a, b, p, q, k$）を動かし、式とグラフの形がどう変化するかをリアルタイムに観察できます。
* **柔軟な出題設定**
  * **出題形式**: 「グラフ → 式」「式 → グラフ」の切り替えが可能。
  * **難易度設定（サポート機能）**: 目盛りから自力で読み取る「実践」と、座標ラベルや特徴点が表示される「サポート」を選べます。
* **充実した学習サポート**
  * **インタラクティブなグラフ**: グラフ上をマウスでなぞる（スマホではタッチする）と、リアルタイムで座標がポップアップ表示されます。
  * **丁寧なステップ解説**: 回答後、着眼点や計算のステップが詳しく表示されます。
  * **比較表示**: 「グラフ→式」モードで間違えた場合、自分が選んだ式のグラフが破線で重なって表示され、正解との違いが一目で分かります。
* **学習の継続をサポート**
  * 正解数・不正解数・連続正解数（ストリーク）・正答率を自動記録。
  * 日本語・英語の二言語切り替え（🌐 JP / EN）に完全対応。

## 📚 学習できる関数の形（出題パターン）

* **直線（一次関数）**
  * $y = ax$, $y = ax + b$
* **放物線（二次関数）**
  * $y = ax^2$, $y = ax^2 + q$, $y = a(x-p)^2$, $y = a(x-p)^2 + q$
* **双曲線（分数関数・反比例）**
  * $y = k/x$, $y = k/(x-p)$, $y = k/(x-p) + q$
* **総合ミックス**: 上記すべてからランダム出題
